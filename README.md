# Handmade — магазин аксессуаров ручной работы

Учебный интернет-магазин: главная, каталог с фильтрами и пагинацией, корзина, избранное, личный кабинет, оформление доставки и админ-панель.

**Стек:** HTML, CSS, JavaScript (без фреймворков), данные корзины и избранного хранятся в localStorage.

- Адаптивная вёрстка от 360px, мобильное меню
- Изображения в WebP (56 МБ → 2,8 МБ), lazy loading
- Анимации появления на IntersectionObserver
